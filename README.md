# AI Portfolio Optimization & Modern Portfolio Theory Dashboard

**Developed by Kamal Lakha | MBA Financial Markets**

A production-ready, interactive web application built with Python and Streamlit. This dashboard demonstrates advanced quantitative finance concepts including Modern Portfolio Theory (MPT), Portfolio Optimization, Risk Analytics, and Monte Carlo Simulations. 

Designed with a premium dark-themed UI (inspired by BlackRock Aladdin and Bloomberg Terminal), this tool provides actionable insights for equity research and portfolio management.

## Features
- **Portfolio Optimizer:** Maximize Sharpe, Minimize Variance, Maximize Return, or Equal Weight.
- **Modern Portfolio Theory:** Interactive Efficient Frontier and Capital Market Line.
- **Risk Analytics:** Beta, Alpha, Sharpe, Sortino, Treynor, Max Drawdown, VaR, CVaR.
- **Monte Carlo Simulation:** 10,000 simulations for future portfolio distributions.
- **Correlation Analysis:** Heatmaps and covariance matrices for diversification insights.
- **Performance Dashboard:** Cumulative returns, rolling metrics, and benchmark comparisons.
- **Automated Reporting:** Export portfolio summary to PDF.

## Installation
```bash
pip install -r requirements.txt
streamlit run app.py
```
